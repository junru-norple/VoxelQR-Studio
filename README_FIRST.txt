==================== ENGLISH ====================

VoxelQR Studio v1.1.1
Dynamic 3D Voxel QR Code Generator

WINDOWS
  Extract the ZIP, then open VoxelQR-Studio.exe.

OFFLINE WEB
  Extract the ZIP, then open VoxelQR-Studio-Web.html in a modern Chromium-based browser.

Neither entry point needs an account, installer, development server, analytics service, or network connection. Version 1.1.1 refines public presentation and interface localization. Product mechanics are unchanged from v1.1.0. Character models, motion, QR generation, Scan behavior, camera controls, export, and offline operation remain the same.

THEMES
  Sakura, Summer Grove, Maple, Ginkgo, Snow Pine, Sunset, Ocean Waves, Pixel Wanderer, and Voxel Kitty.

VoxelQR Studio v1.1.1
3D 動態體素 QR Code 生成器

WINDOWS
  完整解壓縮 ZIP，然後開啟 VoxelQR-Studio.exe。

離線 WEB
  完整解壓縮 ZIP，然後使用現代 Chromium 系瀏覽器開啟 VoxelQR-Studio-Web.html。

兩種入口都不需要帳號、安裝程式、開發伺服器、分析服務或網路連線。v1.1.1 改善公開展示與介面本地化。產品機制與 v1.1.0 相同；角色模型、動態、QR 產生、掃描行為、相機控制、匯出及離線操作均維持不變。

  櫻花、盛夏綠蔭、楓葉、銀杏、雪松、日落、海浪、像素旅兔及 Voxel Kitty。
