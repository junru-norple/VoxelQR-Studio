VoxelQR Studio v1.0.0
3D 動態體素 QR Code 生成器

Windows:
  Open VoxelQR-Studio.exe from the extracted folder.

Offline Web:
  Open VoxelQR-Studio-Web.html in a modern Chromium-based browser.

No account, installer, development server, analytics, or network connection is required.
